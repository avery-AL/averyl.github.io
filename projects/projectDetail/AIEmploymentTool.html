AI Employment Assessment Tool

Automated employment document analysis & candidate assessment

Overview

A scalable platform for automated parsing and evaluation of employment documents, combining OCR, LLM reasoning, and ML scoring to streamline screening workflows.

Tech Stack

Python FastAPI Docker GitHub Actions scikit-learn TensorFlow PostgreSQL Redis

Highlights

  • Designed scalable backend with FastAPI + asyncio for high-throughput requests.
  • Integrated OCR–LLM pipelines (TensorFlow + Python) to minimize manual extraction.
  • Implemented model registry with versioning and A/B testing for continuous improvement.
  • Built CI/CD via GitHub Actions for automated tests, linting, and container deploys.
